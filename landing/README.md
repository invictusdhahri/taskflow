# TaskFlow Landing

Marketing site for [TaskFlow](https://github.com/invictusdhahri/taskflow) — lives in this repo at `Landing/`.

## Stack

- Next.js (App Router)
- Tailwind CSS + shadcn/ui
- Deploy on Vercel (set Root Directory to `Landing`)

## Develop

```bash
cd Landing
npm install
npm run dev
```

## Build

```bash
cd Landing
npm run build
npm start
```

## Notes

- Live GitHub star count is fetched from the public GitHub API and revalidated hourly.
- Optional: set `NEXT_PUBLIC_SITE_URL` for canonical/OG URLs in production.
