# Design Context — TaskFlow Landing

## Target audience

Anyone who wants a structured board on GitHub so they can see and understand what they are doing — developers and builders using Cursor, Claude Code, Codex, or other AI coding agents.

## Use cases

- Discover TaskFlow and trust it enough to install in one paste
- Copy the install command and run it in their terminal
- Understand what the skill does (bootstrap, audit, implementation-ready issues) without reading a long docs site
- Jump to the GitHub repo for stars, source, and details

## Brand personality / tone

Clear, structured, actionable. GitHub-native and terminal-forward — not SaaS-marketing fluff. Precise and helpful; asks before it writes.

## Visual direction

- Cool slate + cyan accent (aligned with TaskFlow cyan badges)
- Light page chrome; dark terminal as the dominant product visual
- Avoid purple/glow “AI default” aesthetics, cream+serif terracotta, and broadsheet newspaper layouts
- Distinctive display + monospace pairing (not Inter/Geist/system defaults)

## Primary action

Copy `npx skills add invictusdhahri/taskflow` and paste into the terminal.

## Differentiation

The install terminal is the hero — not a dashboard mock or feature card grid. Live GitHub stars provide social proof beside the brand.
